# 題庫「上傳題本」流程與確認畫面原則

> **設計文件** · 建立於 2026-10-22（issue #1112）
> 影響：題庫列表「新增題目 ▽」、上傳畫面、綜合確認畫面、擷取（magic paste `exam_paper`；`cloze_group` 為匯入內部使用、沒有端點）、題組音檔、用量記錄。
> 題型分流與加題型檢查清單見 [`question-bank-question-types.md`](./question-bank-question-types.md)；資料表見 [`question-bank-schema.md`](./question-bank-schema.md)「上傳題本（#1112）」段。
> 示意圖（7 張：入口／上傳／逐題核對／編輯／整頁對照／略過核對／小螢幕）：issue #1112 2026-10-21 留言附的連結（不公開，只有 issue 擁有者帳號打得開）。

## 名詞

| 名詞 | 意思 |
|------|------|
| 題本 | 老師上傳的一整份考卷、習作（一個 PDF，或一組照片） |
| 題目卡 | 確認畫面上的一個項目：一道單題，或一整個題組（程式裡稱 unit） |
| 題組主圖文 | 題組上方共用的文章、圖片或對話 |
| 以圖為準題組 | 海報、漫畫這類以整張圖為內容的題組 |
| 原卷題號 | 題目在原本考卷上印的題號，例如 "12"、"40" |
| 未完成的匯入 | 還沒全部存進題庫的上傳題本，可以回來接著做 |

## 一、三條新增路徑（列表「新增題目 ▽」）

| 選項 | 打開的畫面 | 給誰用 |
|------|-----------|--------|
| **上傳題本**（下拉第一項，附一行說明） | 上傳畫面 → 綜合確認畫面（本文件） | 手上有考卷、習作，PDF 或照片都可以 |
| **AI 出題**（停用，標「即將推出（#1114）」） | 綜合確認畫面（#1114） | 不上傳，請 AI 出新題 |
| 分隔線下方「自己出題」：選擇題、閱讀題組、克漏字題組… | 現有的單一題型畫面（`QuestionSheet`） | 自己打字出新題 |

- **現有的「上傳圖片擷取」完全不動**：單一題型畫面左欄的上傳擷取（`QuestionBankBatchPanel` 裡的 `MagicPasteInput`）保持原樣、原功能。「上傳題本」只是另外多一個入口。
- 自己出題維持一次一種題型；混合題型的考卷由派發組卷階段負責，題庫只存一題一題的題目。

## 二、上傳畫面

左邊上傳區，右邊整份設定，頁尾按鈕「開始擷取」。

**上傳區**
- 可以放 **PDF** 或 **多張照片**，兩種不能混用。
- **最多 20 頁**（上傳區上直接寫出來）：照片最多 20 張；PDF 超過 20 頁就擋下，提示老師拆成幾份再上傳。
- 頁尾只顯示「**共 N 頁**」（空白頁也算在 N 頁和 20 頁上限裡）。用量只在後台記錄，老師看不到（見第八節）。
- 畫面：右側編輯面板（不新增路由），寬度和其他「新增題目／新增教材」面板一致——用 `editor-panel` 寫法，左緣貼齊側邊欄、佔滿右側（手機版滿版），背後半透明遮罩；關閉鈕、Esc 會關閉（不停止處理），**點遮罩不關閉**（與 `QuestionSheet` 一致，C4 cold-read B13）。左邊上傳區、右邊整份設定；年段、考題來源、公開、朗讀口音沒填完時「開始擷取」停用，旁邊寫出還缺哪幾項。按「開始擷取」後同一個面板換成（C3 是簡單進度畫面；C4 起）**直接進綜合確認畫面**，題目邊處理邊出現，原進度畫面的每頁狀態與按鈕移到「原卷第 N 頁」換頁那一行（C4 定案 A1）。
- 每頁的說明（第五輪；C4 起顯示在核對畫面「原卷第 N 頁」那一行）：
  - 頁列表上方一行灰色小字「**頁碼是 PDF 檔的頁序，可能和題本上印的頁碼不同**」（例如封面沒印頁碼，題本上印的頁碼會少 1）。
  - 每頁的小縮圖可以點開放大（標準元件 `ZoomableImage`，用 `buttonClassName` 讓按鈕撐滿縮圖框）。
  - 完成但 0 題的頁要說明原因，避免老師以為漏抓（前端從各頁卡片的 `pages`、小題的 `page_no`／`source_question_no` 計算，`exam-import/types.ts` 的 `pageMergeInfo`；後端不改）：
    | 情況 | 顯示 |
    |---|---|
    | 完成、0 題、小題被併入前面的跨頁題組 | 「已併入第 N 頁的題組（第 a–b 題）」；題號取不到就省略括號 |
    | 完成、有題、題組跨頁 | 「完成・擷取 N 題（跨第 a–b 頁）」 |
    | 完成、0 題、沒被併入（封面、封底） | 「沒有題目」 |
  - 底部「共擷取 N 題」總數不變。
- 「新增題目 ▽ → 上傳題本」所有老師都看得到；C3 先開放在「我的題庫」，**機構題庫在 C4 開放**（C3 這一項停用、小字寫「即將推出」）：
  - 建立時帶 `settings.organization_id`，存進那個機構題庫；建立、存入、略過核對都檢查老師仍是該機構成員（不是 → 403）。存進哪個題庫建立後不能改。
  - 「未完成的匯入」提示列在我的題庫、機構題庫**都顯示**，各列各的：我的題庫只列沒有機構／學校的匯入，機構題庫只列該機構的匯入（`GET …/exam-imports?organization_id=`），都只列自己建立的（改寫 C3 cold-read「只在我的題庫顯示」，B13）。
- 已有一份題本正在處理時，「上傳題本」停用，小字寫「目前有一份題本正在處理，處理完才能再上傳」（同一時間只處理一份；直接呼叫開始擷取也會擋下，不建立新匯入）。
- **原始檔大小**：PDF 或任一張照片超過 **100MB** 就在選檔時擋下並提示（避免整份讀進瀏覽器記憶體）。

**整份設定**（每份只填一次，套用到全部題目）
- **年段**：沿用「最低～最高年級」範圍選擇。**老師必選，AI 不判斷**（AI 用母語者標準，容易判斷得偏低）。
- **考題來源**：必填，例如某校段考、習作 U2。原卷題號掛在來源上，所以不能空白。
- **教材包與單元**：選填，選法沿用現有教材關聯欄位。
- **公開設定**：必選，沒有預設值（沿用現行規則）。
- **朗讀口音**：**多選**（美式／英式／印度／澳洲），**預設全不選、至少選一種**；沒選時提醒老師要選。**不記預設**（不存瀏覽器、不存資料庫），每份都重選。
  - 選一種 → 整份都用這種口音（題組主圖文、單題、題組小題全部一樣）。
  - 選多種 → 以「題目卡」為單位**平均分配**一種（輪流洗牌式，避免選了多種卻都抽到同一種）：每道單題各抽一種；每個題組抽一種，題組主圖文（Gemini）和它的小題（Azure）都用這一種。抽中的結果存下來（題目卡上；題組另存 `question_groups.tts_accent`——這個欄位在語音段才加 migration，C4 存入時欄位不存在就不寫；對話文稿每一句先依口音＋角色性別帶平台 Azure 聲音到 `tts_voice`），之後不會自己變。

**上傳前的檢查**
- **同一份題本已經匯入過**：上傳時就比對檔案內容（雜湊），同一位老師匯入過同一份（不含已放棄的匯入）就**擋下**，提示「這個題本已經匯入過」，並附「打開那次匯入」連結。**以老師計、不分題庫**（個人＋機構合計，C4 定案 A3）：409 回應帶 `existing_import_id`、`existing_status`、`existing_organization_id`、`existing_school_id`，前端據此切到那次匯入所在的題庫再打開。
- **每天上限**（以老師計、不分題庫）：一般老師**每天最多上傳 1 本**；平台管理者（`Teacher.is_admin`，與 `magic_paste_quota` 相同的豁免判斷）不限。「一天」以**台灣時間自然日**（00:00–24:00）計；計算當天建立、沒有放棄的匯入，**已放棄的匯入不算**。**不佔**現有「每月 5 張」擷取額度，也不扣老師額度。

## 三、處理方式：前端逐頁送出、邊處理邊顯示

- **PDF 在前端拆頁**（`pdfjs-dist`）：每頁轉成一張圖片，**一頁一個請求**送後端擷取。照片本來就一張一頁。不用 Cloud Run 背景工作，避開請求逾時與回應後 CPU 降速。
- **每頁圖片送出時就上傳 GCS，並記進匯入草稿**（續做、整頁對照、單題截圖都用它）。
- **每頁的結果即時寫進匯入草稿**，所以老師關掉頁面也不會遺失已處理的頁。
- **只有網頁開著才會繼續處理**。關掉上傳 Sheet、切到「教材」分頁都不會中斷（處理狀態放在「我的教材」頁面層，不跟題庫分頁一起卸載）；老師關掉網頁或離開「我的教材」頁，下次從題庫的「**未完成的匯入**」打開，接著處理剩下的頁。
- **停下後接著送**（C3 review）：網路中斷、或有頁被擋下（400 圖片過大／格式、轉圖失敗）時，送出迴圈停下；進度畫面上方顯示「處理停下來了，還有 N 頁沒送出」＋「**繼續處理**」（主按鈕），按了重新跑送出順序（含剛才被擋下的頁）。被擋下的頁也有自己的「重送這一頁」（重新轉圖再送）。從提示列「繼續」打開同一份、檔案還在時也直接接著送。
- **處理順序**：先送**最後一頁**；若是答案頁，再往前一頁檢查，直到遇到不是答案頁的頁為止（答案頁的答案先記下；往前時遇到空白頁就略過、繼續往前）。之後從第 1 頁依序處理其餘頁。**一次只送一頁**，不並行。畫面上的題目卡一律依原卷頁碼與頁內順序排列，不論哪一頁先處理完。
- **前端拆頁與壓縮**（C3）：PDF 固定縮放到長邊約 2000px、照片長邊最多 2400px（依 EXIF 轉正），一律白底輸出 JPEG；超過 9MB（後端上限 10MB 再留餘裕）就降品質、再縮小。pdfjs 關掉 `isEvalSupported`（PDF 內容不能觸發 eval）。

**空白頁**（C3，瀏覽器判斷，保守門檻：寧可多送 AI，也不要把有字的頁略過）
- 算法：用送出前的整頁圖（**不縮小取樣**，縮小會把細字糊成淺灰而漏算）逐點算亮度（0.299R＋0.587G＋0.114B），亮度低於 140 算「墨跡」（淺灰的掃描雜訊、陰影漸層不算）；**墨跡點數占全頁不到 0.01%** 才算空白。以 2000px 寬的 A4 估：只有頁碼約 0.004%（算空白）；一個 12pt 的英文單字約 0.0125%（不算空白，照樣送）。整片深色（照片背景、掃描黑邊）一定不算空白。程式：`frontend/src/components/question-bank/exam-import/blankPage.ts`。
- 空白頁**不送 AI、不記用量**：前端呼叫「標為空白頁」（`POST …/pages/{n}/blank`，附頁圖），後端存頁圖、頁狀態 `done`、0 張題目卡、`error` 放代碼 `BLANK_SKIPPED` 當標記（不加 migration）；整份資料（GET）每頁帶 `blank_skipped`、整份帶 `pages_blank`。
- 空白頁**算已完成**：進度寫「12／16 頁（含 2 頁空白）」。跨頁題組可以越過空白頁合併。
- 空白頁之後按「仍要送出這一頁」而擷取到題目時，越過它合併過的題組會**拆回各頁、整份依頁碼重新合併**（例如第 1 頁題組、第 2 頁誤判空白、第 3 頁延續：送出第 2 頁後題組順序是 1→2→3，而不是 1→3→2），再套一次已知答案。後端合併時在題組卡留下合併前的樣子與併進來的原卡（`_merge_pre`／`_merge_parts`，只在後端，API 不輸出）。
- 進度畫面顯示「空白頁略過」＋縮圖＋「**仍要送出這一頁**」：用後端存好的頁圖送 AI（`POST …/pages/{n}/send-blank`，不必重選檔案），**不算整頁重送次數**；送出後失敗就和一般失敗頁一樣，之後再送才算重送。
- **每頁一次 AI 呼叫**：同一次完成題目卡擷取、答案（頁上有就用）、缺答案的 AI 作答、考點、對話角色性別與年輕／成人。送出時把已知答案（題號 → 答案）一起給 AI，有已知答案的題不再 AI 作答。
- **已處理完的頁不能整頁重送**（後端回 409 `EXAM_IMPORT_PAGE_DONE`，改用「重試」以題為單位重讀）；同一頁同時送兩次，只有一個請求會處理（另一個 409 `EXAM_IMPORT_PAGE_BUSY`）。
- **處理逾時**：一頁的 AI 呼叫**最多等 2 分鐘**，超過就中斷，這一頁標成失敗（錯誤「AI 處理逾時」），後端回 504 `EXAM_IMPORT_AI_TIMEOUT`；用量照記（沒有回應，token 記 0、標失敗；實際用量不得而知，**不估算**，後端 log 標示 `TIMEOUT_USAGE_UNKNOWN`）。
- **處理中超過 3 分鐘可以重送**：請求中途斷掉（關網頁、斷線）時，頁會停在「處理中」；超過 3 分鐘就視同失敗，可以整頁重送。舊的請求如果之後才回來，因為那一頁已經被新的送出接手，舊結果直接丟掉（用量照記），不會重複寫入、也不會把新的處理標成失敗。
- **整頁重送每頁最多 2 次**。**第一次處理不算重送**；失敗後再送、或處理中超過 3 分鐘後再送，才各算一次。已經重送 2 次還要再送，後端回 409 `EXAM_IMPORT_RETRY_LIMIT`、不再呼叫 AI；這時那一頁如果還停在「處理中」超過 3 分鐘，後端順手把它改成失敗（錯誤「處理逾時」），整份匯入才能變成「可以核對」。
- **處理中被放棄**：AI 還在處理時老師按了放棄，AI 回來後結果直接丟掉（用量照記、標失敗），後端回 409 `EXAM_IMPORT_CLOSED`。
- **前端處理 409**（C3 實作）：
  - `EXAM_IMPORT_PAGE_BUSY`：這一頁別的分頁或上一次送出還在處理——不顯示錯誤，維持「第 N 頁處理中…」，隔幾秒重抓整份（GET）看結果；超過 3 分鐘還在處理中就提供「重送這一頁」。
  - `EXAM_IMPORT_RETRY_LIMIT`：這一頁標紅、不再提供「重送這一頁」，改寫「這一頁讀不出來，請手動補題」，老師用「手動補這一題」逐題自己填。
  - `EXAM_IMPORT_PAGE_DONE`：這一頁其實已處理完，重抓整份顯示結果即可。
  - 504 `EXAM_IMPORT_AI_TIMEOUT`：這一頁標紅「處理失敗」，還有重送次數就提供「重送這一頁」。
- 匯入摘要（列表、GET 與各 API 回傳的 `import`）帶 `source`：`{id, name}`，對應 `settings.source_id`；沒設或老師已看不到該來源時為 `null`。
- 整份資料（GET）帶 `retry_limits`（`page_resends`、`question_retries`）、每頁的 `resend_count`、每張題目卡的 `retry_count`，前端據此決定還要不要顯示重送／重試按鈕。
- 題目、選項或文章、答案、考點在同一次 AI 呼叫一起回來，題目卡出現時就齊全；只有**音檔**會晚一點補上。（原本規劃的灰色「考點分析中…」因每頁一次呼叫而不需要。）
- **跨頁題組**：AI 在下一頁標出「延續上一頁的題組」，併回前面最近一個有題目的頁的最後一個題組（跨三頁以上也接得上；中間有頁還沒處理完就等它處理完再併）。克漏字空格編號接續上一頁（只看上一頁文章裡的空格）；合併後整個題組重新做空格對位，並依閱讀順序重編成 1、2、3…（存入題庫時文章空格與小題一一對應）。**單頁的克漏字也一樣**：寫入草稿時就重編成 1、2、3…（例如原卷第 41–45 題印成 41–45 號空格，草稿裡是 1–5），題號仍保留在小題上。
- AI 每題回報它在頁面上的位置（框），用來裁出「原卷這一題的截圖」，以及整頁對照時框出位置。
- 文章插圖、題幹圖、選項圖、以圖為準題組的整張圖**由後端從頁圖裁切**（C4 cold-read B1，Pillow；避免瀏覽器跨網域裁圖的限制，略過核對也不必等前端）：寫入一頁結果時就裁好、存成一般圖片網址寫在題目卡上（題目 `image_url`、`option_image_urls`，題組 `stimulus.image_url`、`figures[i].url`）；當時沒裁到的（上傳失敗、C3 的舊草稿）存入時讀回頁圖補裁。裁圖放一般圖片路徑、不放匯入前綴，放棄匯入時不會刪到已存入題目的圖。「原卷這一題的截圖」只是顯示，前端用頁圖＋題目框顯示即可。現有「上傳圖片擷取」不受影響（仍是前端 `cropImage.ts`）。

**未完成的匯入**
- 保留 **30 天**，份數不限。
- 列表顯示檔名、日期、進度，可以個別「放棄」。
- 畫面（C3）：題庫最上方一條標準 Alert 提示列（沒有未完成的就不顯示；我的題庫、機構題庫各列各的，見第二節）。C4：`ready` 的匯入顯示「待核對」，「繼續」直接進核對畫面。1 份：「你有 1 份題本還沒處理完（檔名，12／16 頁）[繼續][放棄]」；多份：「你有 N 份題本還沒處理完 [查看]」，展開後每份列出檔名、日期、進度，各有 [繼續][放棄]。不用批次操作列（BulkActionBar）。「放棄」先跳確認視窗。
- **繼續時重選檔案**（C3 定案）：瀏覽器不保存老師的檔案，所以「繼續」時：
  - 還有**未送或失敗**的頁 → 請老師「**請再選一次〈檔名〉以繼續處理**」；照片提醒要照第一次的順序選。前端重算雜湊（照片依選取順序串起來算），**雜湊與頁數都相符**才接著送，否則提示「這不是同一份題本」。
  - **全部處理完**（只剩完成、空白頁略過）→ 不用重選，直接看進度。空白頁的「仍要送出這一頁」用後端存好的頁圖，也不必重選。
  - 關掉 Sheet、切到「教材」分頁都不會中斷處理（網頁開著、還在「我的教材」頁就繼續送），提示列同步顯示進度；同一時間只處理一份題本（處理中時「上傳題本」停用）。
- 放棄匯入時，草稿、頁面圖片、已經產生的音檔一起刪除。**已全部存入題庫的匯入不能放棄**；**部分已存入**的匯入可以放棄，已存進題庫的題目（和它們的圖、音檔）保留，只刪草稿與還沒存的卡（C4 cold-read B7）。
- 超過 30 天的未完成匯入目前只是不顯示（也不擋重新上傳），頁面圖片的自動清理排程另議。

## 四、答案

- **答案頁不假設位置**：可能在最後、最前、穿插在中間，學生版可能根本沒有。**每一頁都檢查**是不是答案頁。
- 頁上沒印答案、也沒有已知答案的題，由同一次 AI 呼叫作答（右邊欄紫色 clip「AI 作答」）。答案頁晚到時，依題號回填已處理的頁，**覆蓋成「答案頁」的答案**（灰色 clip「答案頁」）；處理某頁期間別頁的答案頁剛好存好，該頁寫入時也會套用最新的答案。
- **老師改過的答案不覆蓋**。老師改過的答案就是標準答案，不另外加「老師修改」標籤，原本的答案來源 clip 拿掉。
- 題目卡記錄每題的答案來源（答案頁／AI／老師）和「老師改過的欄位」清單；晚到的結果不會蓋掉老師改過的欄位。
- 答案頁晚到時，已經存進題庫、而且老師沒改過答案的題目，直接更新成答案頁的答案（條件：卡上答案來源仍是 AI、老師在核對畫面沒改過答案、題庫裡目前的正確選項仍等於當初存入的 AI 答案；C4 cold-read B3）。
- AI 作答**不算**需注意；所有題目都必須有標準答案才能儲存。

## 五、綜合確認畫面

### 版面

- **頂部整份設定**：年段、教材、來源、公開，改一次**套用到全部**還沒存的題目卡。題目卡上不顯示這四個欄位；存進題庫後要個別調整，到題庫單獨編輯。**口音不在頂部改**，只能逐題組換。
- **頂部藍色進度條**，往下捲也一直看得到。
- 兩個分頁：
  - **逐題核對**：像一份可以編輯的紙本考卷。題目沒有外框、靠留白分開，題組上下各一條細線；原卷換頁處有虛線，標「原卷第 N 頁」；選項全部展開，長文章只顯示前幾行，下方「展開全文」。
  - **整頁對照原卷**：左邊原卷整頁圖，右邊這一頁擷取出的題目；「‹ 第 N／總頁數 ›」兩邊同步換頁；滑鼠停在右邊某題，左邊框出它在原卷的位置；螢幕比筆電窄時改成上下排。
- **處理中的頁**：顯示「第 N 頁處理中…」和灰色佔位條。

### 左側「題號導覽」

題號排成方格，只標色、不移動題目位置：

| 標示 | 意思 |
|------|------|
| 琥珀色（amber） | 缺答案 |
| 紅色 | 處理失敗 |
| 虛線 | 處理中 |
| 藍色「我的題庫已有這題」 | 與自己題庫重複（見第六節），可點開看原題 |

- 下方「需注意 N 題」和「跳到下一題」。有問題的題目，題號旁也有對應顏色的短豎線。
- 小螢幕：導覽收成頂端一條「需注意 N 題　‹　›　▦」，按 ▦ 從底部拉出全部題號；右邊欄內容改放在每題下方一行。

### 右邊欄（對齊每題第一行）

- 答案字母（綠色）；正確選項本身也用綠字加 ✓。
- 答案來源 clip：「答案頁」灰色、「AI 作答」紫色，不加說明文字；老師改過就不顯示。
- 考點 clip（與題目同一次 AI 呼叫產生，不會晚到）。
- 常駐淡灰鉛筆；滑鼠移到題目上整題變淡底色，點任何地方都能編輯。
- 題組標題旁的**小喇叭和時長**（只能試聽）。以圖為準、沒有文字的題組寫「沒有文字可產生音檔」。

### 編輯一題

- 點鉛筆，那一題在**原位置展開成表單**，最上方是原卷這一題的截圖；框歪或 AI 沒給位置時，改看原卷整頁（「框歪了？看原卷整頁」）。
- 表單沿用 `QuestionCard`／`GroupCard`（照題型分流，不複製）。正確答案用選項前的圓圈指定。
- 題組的音檔操作（重新產生、單一題組換口音、上傳自己錄的音檔）只在編輯時出現（見第七節）。
- 編輯時可以「**刪除這一題**」。同一份題本裡出現兩題相同時，由老師自己刪。

### 處理失敗

- **重試以題為單位**：只重讀那一頁的那一題，不整頁重來；整頁失敗才重送整頁（已處理完的頁不能整頁重送）。
- **重試只能針對畫面上已有的題目卡**：送題目卡 id（`card_id`）或題號（頁面圖片 `file` 可省略：沒附就用擷取時存好的頁圖，找不到 409 `EXAM_IMPORT_PAGE_IMAGE_MISSING`；仍接受附檔），位置（`bbox`）只是輔助、不能單獨使用。只給位置 → 422 `EXAM_IMPORT_RETRY_TARGET`；題號比不到任何題目卡 → 404 `EXAM_IMPORT_CARD_NOT_FOUND`；都不呼叫 AI。擷取時**整題漏掉、畫面上沒有卡的題**，老師用「**手動補這一題**」自己填（不用重試新增卡：新增的卡沒有重試次數可算，重複送會疊出重複的卡）。
- 跨頁合併過的題組：重試只換掉指定題號的那一個小題，其他頁併進來的文章與小題保留。
- 指定了題號、AI 重讀結果裡卻沒有那個題號時，回 422 `EXAM_IMPORT_RETRY_EMPTY`（不拿別題頂替），請老師「手動補這一題」。指定的題目卡和題號對不上時回 422 `EXAM_IMPORT_RETRY_TARGET`，不呼叫 AI。
- **重試每題最多 2 次**（次數記在題目卡上 `retry_count`；跨頁合併過的題組整張卡共用一個次數）。**每次為這一題呼叫 AI 就算一次**，不論成功、讀不到這一題、AI 格式錯誤、逾時，或 **AI 供應商錯誤**（連線失敗、服務暫停等，沒有回應所以不記用量，但次數照算）；送 AI 之前就先記上，所以同時按兩次也不會超過。用完還要重試，後端回 409 `EXAM_IMPORT_RETRY_LIMIT`、不再呼叫 AI。
- 前端：`retry_count` 已達上限（`retry_limits.question_retries`）時不再顯示「重試」，只留「**手動補這一題**」；收到 409 `EXAM_IMPORT_RETRY_LIMIT` 也一樣處理。重試逾時（504 `EXAM_IMPORT_AI_TIMEOUT`）照樣算一次。
- **「手動補這一題」＝打開編輯畫面**，讓老師自己填（第一版就要做）。
- 其他還沒做好的按鈕：停用，tooltip「即將推出」（照按鈕層級規則，停用要說明原因）。

### 存入

- **全部儲存**（主按鈕）：匯入完成才能按；還沒完成時停用，tooltip「還有 N 頁處理中」。驗證通過的題目卡存進題庫並從畫面移除；驗證失敗的留在畫面上、標出原因，老師改好再存。後端逐題寫入年段、教材、公開、來源和原卷題號。
- **略過核對，直接存入**（頁尾次要按鈕）：匯入還沒完成也能按，按下先跳確認視窗。
  - 已處理好的頁先存；處理中的頁做完再存。
  - 確認視窗寫明：**網頁開著才會繼續處理**；關掉的話，下次打開「未完成的匯入」接著做，做完自動存入。
  - **缺答案、處理失敗的題目不存**，留在「未完成的匯入」，一定要老師手動補好才存。
  - 與自己題庫重複的題目不存。
- **放棄這次匯入**（頁尾）：刪除草稿、頁面圖片和已產生的音檔（已存入的題目保留）。

**後端規則**（C4a，`services/exam_import_save.py`、`exam_import_edit.py`、`exam_import_convert.py`）
- **轉換只有一份**：存入（全部儲存、略過核對、自動存入）一律把題目卡經 `card_to_payload` 轉成題庫格式，再用 `QuestionCreate`／`QuestionGroupCreate` 驗證——和老師自己出題同一套 422 規則。題組散文段落 → 排版與前端 `paragraphsToLayout` 同規則；老師在核對畫面改過排版時卡片帶 `layout`（＋`passage_text`／`segments`），原樣採用。閱讀題組的 `{{n}}` 轉回底線，克漏字小題 `blank_index`＝卡片 `blank`。
- **整份設定**（年段、教材、來源、公開）存在匯入上，存入時才逐題寫進題庫，所以頂部改一次就套用到全部還沒存的卡。存入前必填年段、來源、公開（422 `EXAM_IMPORT_SETTINGS_INCOMPLETE`，`missing` 列出缺哪些）。**教材擁有權**：個人題庫只能掛自己的教材、機構題庫只能掛該機構的教材，單元必須屬於該教材（422 `EXAM_IMPORT_PROGRAM_LINK_INVALID`）；來源必須是老師看得到的。
- 每題寫入年段、公開、教材、來源，**原卷題號寫進 `question_source_links.source_question_no`**；考點來源記 `ai`（老師改過考點記 `manual`）。存好後卡片記下題庫 id（單題 `question.saved_question_id`；題組卡 `saved_group_id`＋每小題 `saved_question_id`），卡片留在草稿、畫面不再顯示。
- **不存的原因**（回傳 `failed[].reason`＋白話 `message`）：`failed` 處理失敗、`missing_answer` 缺答案、`duplicate` 你的題庫（個人或機構）已有這題、`same_stem` 題目文字與我的題庫某題相同、`duplicate_in_import` 這份題本裡已有相同的題目、`cloze_blanks` 克漏字空格與小題對不上、`invalid` 其他驗證錯誤（附原因）、`pending_continuation` 這個題組可能還有下一頁的內容（頁上最後一張題組、後面還有頁在處理中；全部儲存也不存，等下一頁處理完）。資料庫唯一索引撞到時，只有 `uq_questions_teacher_normalized_stem` 回 `same_stem`，其他約束回 `invalid`。`same_stem` 的卡照 A2 算進「N 題因題庫已有而略過」（`skipped_duplicate_*` 含它們），卡上 `duplicate_of.reason` 保留 `same_stem`，畫面據此標「這題重複」。
- **存前重算重複**（B10）：每張卡存之前即時再比一次，同一批前面剛存的也算。單題「題目文字相同」正是資料表唯一索引 `uq_questions_teacher_normalized_stem` 會擋的情況，事先查出來；萬一仍撞到（並發），只退回那一張，其他照存。
- **完成**（C4 定案 A2）：每頁都處理完（沒有失敗頁），而且還沒存的卡全部是「我的題庫已有」（含題目文字相同）→ 匯入狀態 `saved`、提示列消失，畫面提示「N 題因題庫已有而略過」（回傳 `skipped_duplicate_questions`）。缺答案、處理失敗、同一份題本內重複的卡還在 → 維持 `ready`（提示列「待核對」），老師補好或刪掉才算完成。整頁讀不出來的頁，老師「手動補這一題」補上第一張卡後那一頁改成已處理。
- **略過核對**：`settings.auto_save` 打開；已處理好的頁立即存，之後每頁寫入結果（擷取、仍要送出、重試、標空白頁）後自動再存一次。頁上最後一張是題組、後面還有頁在處理中時先不存（可能還有下一頁的內容）；已存的題組不再併入下一頁的延續卡。補裁圖（寫入時沒裁到的框）在拿匯入鎖之前做完，鎖內不碰 GCS；裁圖與自動存入在 threadpool 執行，不擋事件迴圈。頁圖超過 4000 萬像素不裁（記 warning）。
- **編輯一張卡**（PATCH，卡片格式）：後端比對新舊值，只記有變的欄位到 `teacher_edited`（卡片層記題組欄位、每題記自己的）；改了答案 → `answer_source = "teacher"`（畫面不顯示答案來源，答案頁晚到也不覆蓋）；處理失敗的題補上兩個以上選項改回正常；改完重算重複。和寫入頁結果、重試、存入同一把鎖。跨頁合併紀錄（`_merge_pre`／`_merge_parts`）**只在輸出時剝除，草稿裡保留**；老師改過的題組不再被拆回重算。已存進題庫的卡不能改、刪、重試（409 `EXAM_IMPORT_CARD_SAVED`）。**卡片版本 `rev`**（整數）：卡片內容在後端每變一次就 +1（合併延續頁、答案頁回填、重試換卡、老師 PATCH 等；只比對內容，重複標記 `duplicate_of` 變動不算），統一在寫回頁卡片時（`exam_import_common._touch`）計算。PATCH 可帶打開時看到的 `rev`，和目前不同 → 409 `EXAM_IMPORT_CARD_CHANGED`（`detail.card` 附最新卡片）且不改；沒帶不檢查。**老師編輯過主圖文（卡上有 `layout`／`passage_text`／`segments`）的題組不再併入下一頁的延續卡**：存入用老師的排版，併進去的文章會遺失；延續卡留在自己那一頁當獨立題組，內容不少，由老師核對時處理。跨頁合併時延續頁的插圖（`figures`，`after_paragraph` 加上上一頁段落數、記 `page_no`）與題組主圖一起接上。PATCH 整份設定與 `/save` 一樣檢查老師仍是該題庫成員（403）。

**前端做法**（C4b，`frontend/src/components/question-bank/exam-import/`）
- 面板：`ExamImportSheet` 的 `view` 是上傳（`ExamImportUploadForm`）或核對（`ExamImportReview`）；原「處理進度」畫面（`ExamImportProgress`）已移除，每頁狀態、「重送這一頁」、空白頁「仍要送出這一頁」、「這一頁讀不出來，請手動補題」、跨頁說明、縮圖放大都在「原卷第 N 頁」那一行（`ExamImportReviewPageRow`），處理中的頁顯示「第 N 頁處理中…」＋灰色佔位條；「繼續處理」、重選檔案、頁碼說明小字在頂部（`ExamImportReviewTop`）。捲動區與頁尾右側 `pr-8 sm:pr-16` 閃避老師後台的右側浮動工具列。
- 頂部整份設定改了就 `PATCH …/settings`（年段拖曳停 0.5 秒才送）；來源只存 id，打開時用來源列表查名稱。
- 題號導覽用共用元件 `components/shared/QuestionNumberNav`（ui-style-guide 第 6 節）：題組每小題一格、標籤＝原卷題號（沒有用流水號）；琥珀缺答案、紅失敗（整張卡失敗全組紅，單一小題失敗只標那格）、藍＝題庫已有／題目文字相同／本份重複、灰虛線＝處理中的頁；目前這題粗框淡底；需注意（缺答案、失敗、本份重複、存入被退回）格子旁短豎線，「需注意 N 題」不含題庫已有的（會自動略過，A2）。「跳到下一題」＝目前這題之後的下一個需注意的題。點題庫已有的格子＝捲過去並打開原題（Dialog，以 id 抓題、題庫預覽元件顯示）。小螢幕（< md）只留「需注意 N 題」「跳到下一題」一列，▦ 抽屜在 C4c。
- 唯讀卡片用題庫預覽元件（`QuestionsPreview`／`GroupPreview` 加 `showAnswers`、`numberLabels`、`aside`、`itemAttrs`、`collapsibleStimulus` 擴充），右邊欄＝答案字母、答案來源 clip（答案頁灰、AI 作答紫，`answer_source=teacher` 不顯示）、考點 clip。已存進題庫的卡（`saved_question_id`／`saved_group_id`）不顯示。
- 編輯：一次只展開一張；嵌 `QuestionCard`／`GroupCard`（`hideScopeSettings` 不顯示教材年段、單題不查相似題、`audioDisabledReason` 麥克風停用「即將推出」），上方原卷截圖用整頁圖＋題目框以 CSS 裁（`ExamImportOriginalCrop`，點圖看整頁）。卡片 ↔ 草稿轉換在 `cardDraft.ts`；「完成」只送跟打開時比有改的欄位（題組小題一律帶原卷題號讓後端對回原題；小題增刪或換順序時整份送），沒改不送。題組的音檔操作（喇叭、重新產生、換口音、上傳錄音）先停用＋「即將推出」（A5）。
- 重試用既有 retry API：不附頁圖檔，後端用存好的頁圖（不必在瀏覽器抓 GCS 頁圖）。手動補一題：先選題型（選擇題／閱讀題組／克漏字題組），原卷題號選填，新增後直接展開編輯。
- 全部儲存：還有頁在處理時停用、旁邊寫「還有 N 頁處理中」；結果被退回的卡在卡上標原因（`failed[].message`）並捲到第一張；有題庫已有而略過的顯示「N 題因題庫已有而略過」；`completed` → 關面板、提示列消失。略過核對：確認視窗後 `POST …/skip-review`，已打開時按鈕停用並說明。
- 機構題庫：`OrgMaterialsPage` 以目前工作區的機構建立狀態（`useExamImportHost`），提示列與建立都帶 `organization_id`，公開設定顯示「僅機構／公開」。同一份題本 409 的「打開那次匯入」在別的題庫時，換到那個題庫的題庫分頁（網址帶 `examImport`、機構另帶 `org`）再打開；機構不是目前工作區時提示先切換。

## 六、與自己題庫重複的題目

- **只比對「我自己的題目」**（自己建立、未刪除的；**個人＋機構題庫合計**，C4 定案 A3，與資料表唯一索引一致）。不跟別人的公開題目比：別人的公開題就算一模一樣，也存一份給自己，不在別人的題目上加來源。
- 「相同」的判定（比對前忽略空白、大小寫、標點）：
  - **單題**：題目和選項都相同才算相同（選項順序不同也算相同）。克漏字空格的寫法（`{{n}}`、`____`）不影響比對。
  - **單題題目文字相同、選項不同**也當作重複、不存（C4 定案 Q1）：資料表不允許同一位老師有兩題題目文字相同的單題。題目卡 `duplicate_of` 另帶 `"reason": "same_stem"`，提示文字分開：「題目文字與我的題庫某題相同，請修改題目文字」（A4）；完全相同的提示「你的題庫（個人或機構）已有這題」。
  - **題組**：題組文字相同＋每個小題題目都相同就算相同，**選項不同也算相同**；只有部分小題相同不算。題組文字：閱讀題組用 `passage_text`，對話題組用 segments 串起來的文字。
- 處理：**重複就不存**，不提供「仍要存」。題號導覽標藍色「我的題庫已有這題」，可點開看原題（`duplicate_of.id`）。已存進題庫的卡不參與比對。
- 同一份題本內不會有兩題相同；若出現，老師在編輯時刪掉。

> 這條規則只用在上傳題本。自己出題時的重複偵測範圍維持 schema 文件「權限規則」的「私人題庫＋全部公開題目」。

## 七、語音

**誰負責產生**

| 內容 | 引擎 | 產生時機 |
|------|------|----------|
| 單題（選擇題）題幹、題組裡的小題 | 現有 **Azure**（沿用平台 TTS 設定；口音依第二節分配） | 匯入時 |
| 對話題組主圖文（segments） | **Gemini** 多說話者 | 每個題組擷取完成就自動產生 |
| 克漏字題組主圖文 | **Gemini** | 同上 |
| 散文閱讀文章 | **Gemini** | 同上 |
| 以圖為準、沒有擷取到文字的題組 | 不產生 | 顯示「沒有文字可產生音檔」 |

**Gemini 條件**
- `gemini-2.5-flash-tts`，Vertex AI location `global`。輸出 24kHz 16-bit mono PCM 包成 WAV（Cloud Run 有 ffmpeg 就轉 mp3，沒有就存 WAV）。
- 對話用多說話者模式、只給對話稿；**一次最多 2 人**，3 人以上依對話順序切成「最多 2 人」的連續段落，分別產生再串接。
- **口音與角色指示**：內容最前面加一句 `Say the following in a natural {accent} accent[, as {角色描述}]:`（多說話者同樣加在對話稿最前面）。是否加角色描述由 AI 看內容決定，例如成人男性角色加「中年、低沉」、公告類加「播報」。老師只選口音，不選年紀、不選聲音。
- 一次請求文字 ≤ 4000 bytes；長文切段時**每段都加口音指示**，扣掉指示後每段 ≤ 4000 bytes。
- 克漏字空格 `{{n}}` 送 TTS 前轉成 "blank"。
- **聲音由 AI 挑**：程式內一份固定的聲音目錄（Gemini 30 個預設聲音：聲音名、性別、年輕／成人、風格描述）。AI 擷取時依內容替每個角色挑聲音：同角色全程同聲、不同角色不同聲、性別年齡相符；散文、克漏字的旁白聲音也由 AI 挑。結果存在 `question_group_segments.tts_voice`／`question_groups.tts_voice`。
- **角色性別**：AI 擷取對話時一併判斷每個角色的性別與年輕／成人（Girl／Boy、人名、圖片）；判斷不出來時第一位女聲、第二位男聲輪替，確保聽得出是不同人。

**音檔是每題專屬的**
- 匯入產生的每個音檔都屬於那一題或那一個題組（GCS 路徑含題目或草稿 id），**不走**現有 Azure `tts/{hash}.mp3` 內容雜湊快取，避免日後編輯互相影響。
- 刪除題目（題目或題組軟刪除、寫入 `deleted_at` 時）同時刪掉它的 GCS 音檔；放棄匯入時也連音檔一起刪。

**之後改了怎麼辦**
- **換口音**（編輯時，單一題組單選一種）：**立即**重新產生這一個題組的音檔（主圖文與小題一起，維持同一口音）。
- **改了文字**：AI 產生的音檔先標「文字已改，儲存時會重新產生」，**按儲存才重產**（避免邊打字邊花錢）；還在產生中的舊音檔晚到時直接作廢。老師想先聽可以自己按「重新產生」。
- **上傳自己錄的音檔**（例如課本 CD；出處：issue #1112 內文第 109–113 行）：取代 AI 語音。老師上傳的音檔在文字改了之後**不自動取代**，只標「文字已改，音檔可能不符」；要換回 AI 語音由老師自己按「重新產生」，按之前先問「要用 AI 語音取代你上傳的音檔嗎？」。

## 八、用量記錄（只記不扣）

- 先記錄、不扣老師額度；之後平均到每頁，作為正式收費依據。老師畫面上只看到「共 N 頁」。
- 每份題本記：頁數、題數、整份總計。
- 每次 AI 呼叫記一筆：類型（`extract_page` 擷取一頁＝擷取＋作答＋考點一次完成／`retry_question` 重試單一題／`tts` 語音）、模型、input／output／**thinking token 分開存**（加總時相加）、音檔秒數（TTS）、估算美元（`backend/utils/ai_cost.py` `estimate_cost_usd`）、是否成功。AI 回應被擋、沒有內容或格式錯誤也照記（token 已經花掉）；逾時（2 分鐘）沒有回應，記一筆 0 token 的失敗；處理期間頁被別的送出接手、或匯入已放棄，結果丟掉但用量照記（標失敗）。
- 存進資料庫（現有 magic paste 只寫 logger、無法統計），只在後台查。資料表見 schema 文件。
