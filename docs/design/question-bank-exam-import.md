# 題庫「上傳題本」流程與確認畫面原則

> **設計文件** · 建立於 2026-10-22（issue #1112）
> 影響：題庫列表「新增題目 ▽」、上傳畫面、綜合確認畫面、擷取（magic paste `exam_paper`；`cloze_group` 為匯入內部使用、沒有端點）、題組音檔、用量記錄。
> 題型分流與加題型檢查清單見 [`question-bank-question-types.md`](./question-bank-question-types.md)；資料表見 [`question-bank-schema.md`](./question-bank-schema.md)「上傳題本（#1112）」段。
> 示意圖（7 張：入口／上傳／逐題核對／編輯／整頁對照／略過核對／小螢幕）：issue #1112 2026-10-21 留言附的連結（不公開，只有 issue 擁有者帳號打得開）。

## 名詞

| 名詞 | 意思 |
|------|------|
| 題本 | 老師上傳的一整份考卷、習作（一個 PDF，或一組照片） |
| 題目卡 | 確認畫面上的一個項目：一道單題，或一整個題組（程式裡稱 unit） |
| 題組主圖文 | 題組上方共用的文章、圖片或對話 |
| 以圖為準題組 | 海報、漫畫這類以整張圖為內容的題組 |
| 原卷題號 | 題目在原本考卷上印的題號，例如 "12"、"40" |
| 未完成的匯入 | 還沒全部存進題庫的上傳題本，可以回來接著做 |

## 一、三條新增路徑（列表「新增題目 ▽」）

| 選項 | 打開的畫面 | 給誰用 |
|------|-----------|--------|
| **上傳題本**（下拉第一項，附一行說明） | 上傳畫面 → 綜合確認畫面（本文件） | 手上有考卷、習作，PDF 或照片都可以 |
| **AI 出題**（停用，標「即將推出（#1114）」） | 綜合確認畫面（#1114） | 不上傳，請 AI 出新題 |
| 分隔線下方「自己出題」：選擇題、閱讀題組、克漏字題組… | 現有的單一題型畫面（`QuestionSheet`） | 自己打字出新題 |

- **現有的「上傳圖片擷取」完全不動**：單一題型畫面左欄的上傳擷取（`QuestionBankBatchPanel` 裡的 `MagicPasteInput`）保持原樣、原功能。「上傳題本」只是另外多一個入口。
- 自己出題維持一次一種題型；混合題型的考卷由派發組卷階段負責，題庫只存一題一題的題目。

## 二、上傳畫面

左邊上傳區，右邊整份設定，頁尾按鈕「開始擷取」。

**上傳區**
- 可以放 **PDF** 或 **多張照片**，兩種不能混用。
- **最多 20 頁**（上傳區上直接寫出來）：照片最多 20 張；PDF 超過 20 頁就擋下，提示老師拆成幾份再上傳。
- 頁尾只顯示「**共 N 頁**」。用量只在後台記錄，老師看不到（見第八節）。

**整份設定**（每份只填一次，套用到全部題目）
- **年段**：沿用「最低～最高年級」範圍選擇。**老師必選，AI 不判斷**（AI 用母語者標準，容易判斷得偏低）。
- **考題來源**：必填，例如某校段考、習作 U2。原卷題號掛在來源上，所以不能空白。
- **教材包與單元**：選填，選法沿用現有教材關聯欄位。
- **公開設定**：必選，沒有預設值（沿用現行規則）。
- **朗讀口音**：**多選**（美式／英式／印度／澳洲），**預設全不選、至少選一種**；沒選時提醒老師要選。**不記預設**（不存瀏覽器、不存資料庫），每份都重選。
  - 選一種 → 整份都用這種口音（題組主圖文、單題、題組小題全部一樣）。
  - 選多種 → 以「題目卡」為單位**平均分配**一種（輪流洗牌式，避免選了多種卻都抽到同一種）：每道單題各抽一種；每個題組抽一種，題組主圖文（Gemini）和它的小題（Azure）都用這一種。抽中的結果存下來（題目卡上；題組另存 `question_groups.tts_accent`），之後不會自己變。

**上傳前的檢查**
- **同一份題本已經匯入過**：上傳時就比對檔案內容（雜湊），同一位老師匯入過同一份（不含已放棄的匯入）就**擋下**，提示「這個題本已經匯入過」，並附「打開那次匯入」連結。
- **每天上限**：一般老師**每天最多上傳 1 本**；平台管理者（`Teacher.is_admin`，與 `magic_paste_quota` 相同的豁免判斷）不限。「一天」以**台灣時間自然日**（00:00–24:00）計；計算當天建立、沒有放棄的匯入，**已放棄的匯入不算**。**不佔**現有「每月 5 張」擷取額度，也不扣老師額度。

## 三、處理方式：前端逐頁送出、邊處理邊顯示

- **PDF 在前端拆頁**（`pdfjs-dist`）：每頁轉成一張圖片，**一頁一個請求**送後端擷取。照片本來就一張一頁。不用 Cloud Run 背景工作，避開請求逾時與回應後 CPU 降速。
- **每頁圖片送出時就上傳 GCS，並記進匯入草稿**（續做、整頁對照、單題截圖都用它）。
- **每頁的結果即時寫進匯入草稿**，所以老師關掉頁面也不會遺失已處理的頁。
- **只有網頁開著才會繼續處理**。老師關掉頁面，下次從題庫的「**未完成的匯入**」打開，接著處理剩下的頁。
- **處理順序**：先送**最後一頁**；若是答案頁，再往前一頁檢查，直到遇到不是答案頁的頁為止（答案頁的答案先記下）。之後從第 1 頁依序處理其餘頁。畫面上的題目卡一律依原卷頁碼與頁內順序排列，不論哪一頁先處理完。
- **每頁一次 AI 呼叫**：同一次完成題目卡擷取、答案（頁上有就用）、缺答案的 AI 作答、考點、對話角色性別與年輕／成人。送出時把已知答案（題號 → 答案）一起給 AI，有已知答案的題不再 AI 作答。
- **已處理完的頁不能整頁重送**（後端回 409，改用「重試」以題為單位重讀）；同一頁同時送兩次，只有一個請求會處理（另一個 409）。
- 題目、選項或文章、答案、考點在同一次 AI 呼叫一起回來，題目卡出現時就齊全；只有**音檔**會晚一點補上。（原本規劃的灰色「考點分析中…」因每頁一次呼叫而不需要。）
- **跨頁題組**：AI 在下一頁標出「延續上一頁的題組」，併回前面最近一個有題目的頁的最後一個題組（跨三頁以上也接得上；中間有頁還沒處理完就等它處理完再併）。克漏字空格編號接續上一頁；合併後整個題組重新做空格對位。
- AI 每題回報它在頁面上的位置（框），用來裁出「原卷這一題的截圖」，以及整頁對照時框出位置。
- 文章插圖、題幹圖、選項圖從頁面圖片裁切（沿用 `cropImage.ts`）。以前 PDF 不能裁圖的限制，在上傳題本裡因為已先轉成圖片而解決；現有「上傳圖片擷取」不受影響。

**未完成的匯入**
- 保留 **30 天**，份數不限。
- 列表顯示檔名、日期、進度，可以個別「放棄」。
- 放棄匯入時，草稿、頁面圖片、已經產生的音檔一起刪除。**已全部存入題庫的匯入不能放棄**。
- 超過 30 天的未完成匯入目前只是不顯示（也不擋重新上傳），頁面圖片的自動清理排程另議。

## 四、答案

- **答案頁不假設位置**：可能在最後、最前、穿插在中間，學生版可能根本沒有。**每一頁都檢查**是不是答案頁。
- 頁上沒印答案、也沒有已知答案的題，由同一次 AI 呼叫作答（右邊欄紫色 clip「AI 作答」）。答案頁晚到時，依題號回填已處理的頁，**覆蓋成「答案頁」的答案**（灰色 clip「答案頁」）；處理某頁期間別頁的答案頁剛好存好，該頁寫入時也會套用最新的答案。
- **老師改過的答案不覆蓋**。老師改過的答案就是標準答案，不另外加「老師修改」標籤，原本的答案來源 clip 拿掉。
- 題目卡記錄每題的答案來源（答案頁／AI／老師）和「老師改過的欄位」清單；晚到的結果不會蓋掉老師改過的欄位。
- 答案頁晚到時，已經存進題庫、而且老師沒改過答案的題目，直接更新成答案頁的答案。
- AI 作答**不算**需注意；所有題目都必須有標準答案才能儲存。

## 五、綜合確認畫面

### 版面

- **頂部整份設定**：年段、教材、來源、公開，改一次**套用到全部**還沒存的題目卡。題目卡上不顯示這四個欄位；存進題庫後要個別調整，到題庫單獨編輯。**口音不在頂部改**，只能逐題組換。
- **頂部藍色進度條**，往下捲也一直看得到。
- 兩個分頁：
  - **逐題核對**：像一份可以編輯的紙本考卷。題目沒有外框、靠留白分開，題組上下各一條細線；原卷換頁處有虛線，標「原卷第 N 頁」；選項全部展開，長文章只顯示前幾行，下方「展開全文」。
  - **整頁對照原卷**：左邊原卷整頁圖，右邊這一頁擷取出的題目；「‹ 第 N／總頁數 ›」兩邊同步換頁；滑鼠停在右邊某題，左邊框出它在原卷的位置；螢幕比筆電窄時改成上下排。
- **處理中的頁**：顯示「第 N 頁處理中…」和灰色佔位條。

### 左側「題號導覽」

題號排成方格，只標色、不移動題目位置：

| 標示 | 意思 |
|------|------|
| 琥珀色（amber） | 缺答案 |
| 紅色 | 處理失敗 |
| 虛線 | 處理中 |
| 藍色「我的題庫已有這題」 | 與自己題庫重複（見第六節），可點開看原題 |

- 下方「需注意 N 題」和「跳到下一題」。有問題的題目，題號旁也有對應顏色的短豎線。
- 小螢幕：導覽收成頂端一條「需注意 N 題　‹　›　▦」，按 ▦ 從底部拉出全部題號；右邊欄內容改放在每題下方一行。

### 右邊欄（對齊每題第一行）

- 答案字母（綠色）；正確選項本身也用綠字加 ✓。
- 答案來源 clip：「答案頁」灰色、「AI 作答」紫色，不加說明文字；老師改過就不顯示。
- 考點 clip（與題目同一次 AI 呼叫產生，不會晚到）。
- 常駐淡灰鉛筆；滑鼠移到題目上整題變淡底色，點任何地方都能編輯。
- 題組標題旁的**小喇叭和時長**（只能試聽）。以圖為準、沒有文字的題組寫「沒有文字可產生音檔」。

### 編輯一題

- 點鉛筆，那一題在**原位置展開成表單**，最上方是原卷這一題的截圖；框歪或 AI 沒給位置時，改看原卷整頁（「框歪了？看原卷整頁」）。
- 表單沿用 `QuestionCard`／`GroupCard`（照題型分流，不複製）。正確答案用選項前的圓圈指定。
- 題組的音檔操作（重新產生、單一題組換口音、上傳自己錄的音檔）只在編輯時出現（見第七節）。
- 編輯時可以「**刪除這一題**」。同一份題本裡出現兩題相同時，由老師自己刪。

### 處理失敗

- **重試以題為單位**：只重讀那一頁的那一題（送頁面圖片＋題號／位置，或題目卡 id），不整頁重來；整頁失敗才重送整頁（已處理完的頁不能整頁重送）。
- 跨頁合併過的題組：重試只換掉指定題號的那一個小題，其他頁併進來的文章與小題保留；AI 重讀結果裡找不到那個題號時回報失敗，請老師「手動補這一題」。
- **「手動補這一題」＝打開編輯畫面**，讓老師自己填（第一版就要做）。
- 其他還沒做好的按鈕：停用，tooltip「即將推出」（照按鈕層級規則，停用要說明原因）。

### 存入

- **全部儲存**（主按鈕）：匯入完成才能按；還沒完成時停用，tooltip「還有 N 頁處理中」。驗證通過的題目卡存進題庫並從畫面移除；驗證失敗的留在畫面上、標出原因，老師改好再存。後端逐題寫入年段、教材、公開、來源和原卷題號。
- **略過核對，直接存入**（頁尾次要按鈕）：匯入還沒完成也能按，按下先跳確認視窗。
  - 已處理好的頁先存；處理中的頁做完再存。
  - 確認視窗寫明：**網頁開著才會繼續處理**；關掉的話，下次打開「未完成的匯入」接著做，做完自動存入。
  - **缺答案、處理失敗的題目不存**，留在「未完成的匯入」，一定要老師手動補好才存。
  - 與自己題庫重複的題目不存。
- **放棄這次匯入**（頁尾）：刪除草稿、頁面圖片和已產生的音檔。

## 六、與自己題庫重複的題目

- **只比對「我自己的題目」**（自己建立、未刪除的）。不跟別人的公開題目比：別人的公開題就算一模一樣，也存一份給自己，不在別人的題目上加來源。
- 「相同」的判定（比對前忽略空白、大小寫、標點）：
  - **單題**：題目和選項都相同才算相同（選項順序不同也算相同）。克漏字空格的寫法（`{{n}}`、`____`）不影響比對。
  - **題組**：題組文字相同＋每個小題題目都相同就算相同，**選項不同也算相同**；只有部分小題相同不算。題組文字：閱讀題組用 `passage_text`，對話題組用 segments 串起來的文字。
- 處理：**重複就不存**，不提供「仍要存」。題號導覽標藍色「我的題庫已有這題」，可點開看原題。
- 同一份題本內不會有兩題相同；若出現，老師在編輯時刪掉。

> 這條規則只用在上傳題本。自己出題時的重複偵測範圍維持 schema 文件「權限規則」的「私人題庫＋全部公開題目」。

## 七、語音

**誰負責產生**

| 內容 | 引擎 | 產生時機 |
|------|------|----------|
| 單題（選擇題）題幹、題組裡的小題 | 現有 **Azure**（沿用平台 TTS 設定；口音依第二節分配） | 匯入時 |
| 對話題組主圖文（segments） | **Gemini** 多說話者 | 每個題組擷取完成就自動產生 |
| 克漏字題組主圖文 | **Gemini** | 同上 |
| 散文閱讀文章 | **Gemini** | 同上 |
| 以圖為準、沒有擷取到文字的題組 | 不產生 | 顯示「沒有文字可產生音檔」 |

**Gemini 條件**
- `gemini-2.5-flash-tts`，Vertex AI location `global`。輸出 24kHz 16-bit mono PCM 包成 WAV（Cloud Run 有 ffmpeg 就轉 mp3，沒有就存 WAV）。
- 對話用多說話者模式、只給對話稿；**一次最多 2 人**，3 人以上依對話順序切成「最多 2 人」的連續段落，分別產生再串接。
- **口音與角色指示**：內容最前面加一句 `Say the following in a natural {accent} accent[, as {角色描述}]:`（多說話者同樣加在對話稿最前面）。是否加角色描述由 AI 看內容決定，例如成人男性角色加「中年、低沉」、公告類加「播報」。老師只選口音，不選年紀、不選聲音。
- 一次請求文字 ≤ 4000 bytes；長文切段時**每段都加口音指示**，扣掉指示後每段 ≤ 4000 bytes。
- 克漏字空格 `{{n}}` 送 TTS 前轉成 "blank"。
- **聲音由 AI 挑**：程式內一份固定的聲音目錄（Gemini 30 個預設聲音：聲音名、性別、年輕／成人、風格描述）。AI 擷取時依內容替每個角色挑聲音：同角色全程同聲、不同角色不同聲、性別年齡相符；散文、克漏字的旁白聲音也由 AI 挑。結果存在 `question_group_segments.tts_voice`／`question_groups.tts_voice`。
- **角色性別**：AI 擷取對話時一併判斷每個角色的性別與年輕／成人（Girl／Boy、人名、圖片）；判斷不出來時第一位女聲、第二位男聲輪替，確保聽得出是不同人。

**音檔是每題專屬的**
- 匯入產生的每個音檔都屬於那一題或那一個題組（GCS 路徑含題目或草稿 id），**不走**現有 Azure `tts/{hash}.mp3` 內容雜湊快取，避免日後編輯互相影響。
- 刪除題目（題目或題組軟刪除、寫入 `deleted_at` 時）同時刪掉它的 GCS 音檔；放棄匯入時也連音檔一起刪。

**之後改了怎麼辦**
- **換口音**（編輯時，單一題組單選一種）：**立即**重新產生這一個題組的音檔（主圖文與小題一起，維持同一口音）。
- **改了文字**：AI 產生的音檔先標「文字已改，儲存時會重新產生」，**按儲存才重產**（避免邊打字邊花錢）；還在產生中的舊音檔晚到時直接作廢。老師想先聽可以自己按「重新產生」。
- **上傳自己錄的音檔**（例如課本 CD；出處：issue #1112 內文第 109–113 行）：取代 AI 語音。老師上傳的音檔在文字改了之後**不自動取代**，只標「文字已改，音檔可能不符」；要換回 AI 語音由老師自己按「重新產生」，按之前先問「要用 AI 語音取代你上傳的音檔嗎？」。
