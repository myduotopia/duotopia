# 魔術貼上 — 統一批次輸入 + 緊湊設定 重新設計

- **Issue**: #891（教材內容魔術貼上）後續 UX 優化
- **日期**: 2026-07-16
- **示意圖**: https://claude.ai/code/artifact/fcb47659-e35a-4180-a2ba-05260add92fc
- **狀態**: 設計定案，待實作

---

## 1. 背景與問題

第一版魔術貼上（PR #943）已上線：單字集 / 例句集 / 朗讀評測都能上傳圖片或 PDF，
AI 擷取內容後預覽插入。但現行 UX 有三個問題：

1. **兩種批次輸入分離**：「貼上文字」（`BatchWorkPanel` 的文字貼上區）與「上傳圖片/PDF」
   （獨立的 `MagicPasteDialog`）是兩個入口，但它們本質是互斥的「批次新增」動作。
2. **設定重複且脫節**：`MagicPasteDialog` 自帶一組「翻譯 / 例句」模式切換，與
   `BatchWorkPanel` 既有的「AI 生成翻譯 / 語音 / 例句」設定各走各的，邏輯重複、行為可能不一致。
3. **設定區過高**：翻譯 / 語音 / 例句三張色卡永遠展開、標籤上下堆疊、下拉選單撐滿寬，
   整個設定區在只用到翻譯時仍佔據大量垂直空間。

## 2. 目標

- 把「貼上文字」與「圖片/PDF」合併成**同一個批次新增區，用 tab 切換**。
- AI 翻譯 / 語音 / 例句設定**兩種輸入方式共用同一組**；移除 `MagicPasteDialog` 自帶的切換。
- 圖片/PDF 擷取只拿原文與圖上已有資訊；**翻譯 / 例句 / 語音在「插入」時**依共用設定補齊，
  與「貼上文字」走同一條補洞管線。
- 設定區重排：**關掉的設定只留一行、開啟才展開**，標籤內嵌、下拉收窄。功能不變。

### 非目標（YAGNI）

- 不改配額 / 計費邏輯（沿用現有 `magic_paste_quota`）。
- 不改支援的檔案類型、AI 供應商切換（沿用 Vertex/OpenAI）。
- 不做「記住上次設定」的持久化（v1 用既有預設；可日後加）。
- 不動批改頁 / 作業副本（`isAssignmentCopy` 仍不顯示魔術貼上）。

## 3. 現況架構

共用元件（單字集 `VocabularySetPanel` 與 例句集/朗讀 `ReadingAssessmentPanel` 皆用）：

- `shared/BatchWorkPanel.tsx` — 桌面左側批次工作區，組合下列子元件 + `children` slot：
  - `shared/BatchPasteArea.tsx` — 文字貼上 textarea
  - `shared/BatchTranslateSettings.tsx` — AI 生成翻譯 + 語言下拉（+ 自訂語言）
  - `shared/BatchTTSSettings.tsx` — AI 生成語音 + 口音 / 性別 / 語速
  - （消費端透過 `children` 傳入）AI 生成例句卡：難度 A1–C2 + 提示 textarea + 翻譯成
  - （消費端透過 `children` 傳入，PR #943 加的）魔術貼上按鈕
- `shared/MagicPasteDialog.tsx` — 獨立 Dialog：上傳 → 擷取 → 預覽 → 插入；**自帶**翻譯/例句模式切換。
- 手機版：各 panel 另有一個 batch paste `Dialog`（純文字貼上）。

## 4. 設計

### 4.1 統一的「批次新增」面板（tab 化）

把 `BatchWorkPanel` 從「單一文字貼上區」升級為「tab 化的批次輸入區」：

```
┌─ 批次新增 ─────────────────────────┐
│  [ ✏️ 貼上文字 ] [ 🖼️ 圖片 / PDF ]   │  ← tabs
│  ┌──────────────────────────────┐  │
│  │  << 當前 tab 的輸入內容 >>     │  │
│  └──────────────────────────────┘  │
│  ── 套用設定（共用，緊湊可收合）──   │
│  ☑ AI 自動翻譯            語言[中文▾] │
│  ☑ AI 生成語音                       │
│     口音[Random▾] 性別[..] 語速[..]  │
│  ☐ AI 生成例句 Beta                  │
│  [ 主要動作按鈕 ]  [ 取消/暫停 ]     │
└──────────────────────────────────────┘
```

- **Tab A「貼上文字」**：內容 = 現有 `BatchPasteArea`；主按鈕 = 「確認貼上」（行為不變）。
- **Tab B「圖片 / PDF」**：內容 = 上傳區 →（擷取後）→ 預覽清單；
  主按鈕 = 「開始擷取」→ 擷取成功後變「插入項目」。
- 兩個 tab **共用**下方設定與主按鈕列。主按鈕文案由「當前 tab + 狀態」決定。
- **元件邊界**：新增 `shared/BatchInputTabs.tsx`（或在 `BatchWorkPanel` 內部）承載 tab 切換與
  兩個 tab 的內容；圖片 tab 的上傳/擷取/預覽邏輯從 `MagicPasteDialog` 抽成
  `shared/MagicPasteInput.tsx`（純輸入，不含設定、不含 Dialog 外殼）。
- 手機版 batch paste `Dialog` 內嵌同一個 `BatchInputTabs`，行為一致。
- `MagicPasteDialog.tsx` 退場（其上傳/擷取/預覽 UI 移入 `MagicPasteInput`；自帶的翻譯/例句切換移除）。

### 4.2 共用設定 + 前置把關

- 三個設定（翻譯 / 語音 / 例句）套用到**當前 tab 的產出**，不論來源是文字或圖片。
- **把關**：若「AI 自動翻譯」勾選但未選語言（含自訂語言為空）→ 主按鈕 `disabled` + 顯示提示
  「請先選好翻譯語言」。兩個 tab 共用此把關。
- 例句設定仍只在單字集情境有意義（例句集/朗讀本身就是句子）；沿用現有「單字集才顯示例句卡」的規則。

### 4.3 資料流：擷取拿原文，插入時補洞

**關鍵決策：翻譯在「插入時」做（非擷取時）。**

1. **擷取（後端）**：AI 只回傳 `text` ＋ 圖上**已印出**的 `translation` / `example_sentence`。
   **不在擷取步驟 AI 生成翻譯或例句。**
   - 影響：後端 `extract_mode` 保留（vocabulary/sentence 決定抓單字或句子）；
     `translate_mode` / `example_mode` 的 `"ai"` 選項在此流程不再使用 —— 前端一律送 `image_first`
     （即「只擷取圖上有的」）。prompt 對應調整：明確「只抄圖上有的翻譯/例句，沒有就留空」。
2. **預覽（前端）**：顯示擷取結果，逐項可勾選 / 編輯。圖上有翻譯的欄位已填、沒有的留空。
3. **插入（前端）**：把勾選項插入右側 rows，接著**依共用設定補洞**，重用既有批次管線：
   - 缺翻譯 且 自動翻譯 on → 用選定語言翻譯（重用 `handleBatchGenerateDefinitions` 系列）。
   - 缺例句 且 生成例句 on（單字集）→ AI 生成（重用 `generateSentences` 系列）。
   - 生成語音 on → 產生 TTS。
   - **補洞只填「空的」欄位** —— 圖上已有的翻譯/例句一律保留，不重打 AI（省成本、尊重原圖）。

**理由**：
- 只有一條翻譯 / 例句 / 語音管線，與「貼上文字」完全一致，語言（含日/韓/自訂）行為統一。
- 圖上已有資訊直接沿用，不做多餘且較貴的 AI 呼叫。
- 移除 `MagicPasteDialog` 自帶切換，減少重複與不一致。

### 4.4 緊湊設定區排版（功能不變）

- **收合**：設定關閉時只顯示一行（checkbox + 標題）；開啟才展開細項。最大的高度壓縮來源。
- **內嵌標籤**：小控制項（翻譯語言、翻譯成）放標題行右側；不再「標籤獨佔一行、控制項在下」。
- **窄下拉**：口音 / 性別 / 語速改 3 欄並排的窄選單；語言選單收窄。
- **輕量化**：去掉厚重色卡與大內距，統一為輕邊框清單，重點色用在勾選框。
- **例句卡**：難度 A1–C2 chips + 提示 textarea（縮為一行高、可下拉）+ 翻譯成內嵌標題行。
- 預設展開狀態沿用現有預設（自動翻譯 on、語音依現況、例句預設收合）。

| 元件 | 責任 | 變更 |

| `BatchWorkPanel` | 桌面批次工作區外殼 | 內嵌 `BatchInputTabs`；設定改緊湊可收合 |

| `MagicPasteInput`（新，由 `MagicPasteDialog` 抽出） | 上傳 / 擷取 / 預覽，回傳擷取項目 | 新增（移除自帶設定） |
| `MagicPasteDialog` | — | 退場 |

| `VocabularySetPanel` / `ReadingAssessmentPanel` | 消費端 | 接 `BatchInputTabs`；插入時補洞掛既有批次管線；手機 Dialog 同步 |
| 後端 `magic_paste_service` | 擷取 | prompt 改為「只抄圖上有的翻譯/例句」；前端固定送 `image_first` |

## 6. 錯誤處理

- 擷取失敗（AI / 截斷）：沿用現有 502 處理與 JSON 截斷救援；預覽顯示錯誤，不插入。
- 配額用盡：沿用現有 402 → 超額提示導向訂閱/購買。
- 補洞失敗（翻譯/例句/TTS）：沿用既有批次管線的 fallback（單項失敗不影響其他項；插入的原文保留）。
- 把關未過（翻譯無語言）：主按鈕停用，不送出。

## 7. 測試計畫

**前端**
- Tab 切換：主按鈕文案隨 tab + 狀態變化（確認貼上 / 開始擷取 / 插入項目）。
- 把關：自動翻譯 on 且無語言 → 主按鈕 disabled + 提示；選語言後解除。
- 收合：關閉設定 → 細項隱藏；開啟 → 顯示。
- 插入補洞：圖上已有翻譯的項目**不重譯**；空的項目依選定語言翻譯；例句同理（單字集）。
- 兩個消費端（單字集 / 例句集）都套用；作業副本不顯示。

**後端**
- prompt（image_first）：不含 AI 生成翻譯/例句的指示，明確「沒有就留空」。
- 既有 30 個魔術貼上測試維持綠燈。

## 8. 範圍與風險

- **範圍**：中大型前端重構，動到 `BatchWorkPanel`（雙 panel 共用）+ 抽出 `MagicPasteInput`
  + 插入補洞接線 + 後端 prompt 調整。後端邏輯改動小。
- **風險**：
  - `BatchWorkPanel` 是共用元件，改動需同時驗證單字集與例句集兩條路徑（含手機版）。
  - 「插入時補洞只填空欄」需確認既有批次生成器能 scope 到指定 rows 且跳過已填欄位；
    若不能，需小幅擴充生成器參數（低風險）。
  - prompt 從「可 AI 生成」改為「只抄圖上有的」屬行為改變，需回歸測試截取品質。
